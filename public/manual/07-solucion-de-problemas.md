# 7. Solución de problemas

| **Mensaje o situación** | **Causa probable** | **Solución** |
| --- | --- | --- |
| “Correo o contraseña incorrectos” | Datos de acceso mal escritos. | Verifique el correo y la contraseña o use la recuperación de contraseña. |
| “No encontramos una cuenta con ese correo” | El correo no está registrado. | Regístrese en la pestaña **Registrarse**. |
| “La contraseña debe tener al menos 6 caracteres” | Contraseña demasiado corta. | Use una contraseña de 6 caracteres o más. |
| “Las contraseñas no coinciden” | La confirmación es distinta a la contraseña. | Escriba la misma contraseña en ambos campos. |
| “El código debe tener 6 dígitos” | Código de recuperación incompleto. | Copie el código completo del correo recibido. |
| “Código inválido” | Código de acceso mal escrito o inexistente. | Verifique el código; si persiste, contacte a soporte. |
| “Código bloqueado por exceso de dispositivos” | El código superó el número de dispositivos permitidos. | Contacte a soporte para su revisión. |
| “Pago aún no confirmado” | El proveedor aún no confirma la transacción. | Espere unos segundos y vuelva a intentar. No repita el pago. |
| La generación con IA tarda o no finaliza | Conexión inestable o alta demanda del servicio. | Verifique su conexión, espere y vuelva a generar. No cierre la pestaña durante la generación. |
| No encuentro una destreza | Código incompleto o de otro subnivel. | Busque por el inicio del código (por ejemplo, M.3.1) o navegue desde **Explorar**. |
| Adaptación curricular deshabilitada | No existe una planificación de origen. | Abra un plan diario o semanal, o una planificación de Currículo por Competencias con NEE, y cree la adaptación desde su detalle. |
| El archivo no se descarga | El navegador bloquea las descargas o ventanas emergentes. | Permita las descargas para el sitio e intente de nuevo. |
